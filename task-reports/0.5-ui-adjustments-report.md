## Selection behaviour

Selection is **local UI state in each room** — `let selectedId = $state(...)` in
both `ConsoleRoom` and `MixerRoom`. There is no store, no persistence, and no
cross-room synchronisation: selecting a channel in Console does not change the
Mixer's selection, and vice versa. This preserves the Task 0.5 scope boundary.

Strips are real `<button type="button">` elements with `aria-pressed`, so
selection works with mouse, Enter/Space, and assistive technology.

Verified in the live app, at 1024×768, in **both** rooms:

| Step | Console panel | Mixer panel |
| --- | --- | --- |
| Room entry | Track 01 | Track 01 |
| Click Track 07 | Track 07 | Track 07 |
| Click Delay Return | Delay Return | Delay Return |
| Strips with `aria-pressed="true"` | exactly 1 | exactly 1 |

## Decisions requiring owner input

1. **The Mixer room header is still visible** (red-banded in image 2). I did not
   hide it, because the Console row of the same request treats the room header
   as wanted, and hiding it was only ever done for Arrange at your explicit
   request. If you want the Mixer header gone too, say so — it is a one-line
   change now that `RoomShell` supports `hideHeader`.
2. **The red box over the meter bridge's dotted border and the channel bank's
   outline** — these read as the region boundaries rather than text to delete,
   and deleting them would remove the zone frames. Left in place. If you meant
   the frames, that is a separate change.
3. **Tab order differs from the product plan.** §14 phrases the shell as
   "Console/Arrange/Mixer navigation". The reordered tabs are your explicit
   decision and the plan does not state tab order as a requirement, but the
   divergence is recorded here rather than silently applied.
4. **Two panels are now duplicated across rooms by design.** Console and Mixer
   both render the selected-channel panel and the channel bank. They share
   components, but each holds its own independent selection state. Confirm that
   the two rooms having separate selections is what you want at this stage.
