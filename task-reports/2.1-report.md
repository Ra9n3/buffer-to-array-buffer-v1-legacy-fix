## Rendering — exactly how each requirement is met

### Housing (spec §4a, plan §4: warm charcoal, bevels, recesses, walnut trim, restrained detail)

* **Deck.** `background-color: var(--al-material-panel)` under three stacked
  gradients: a 180° trim line along the top (1 px clear, 1 px of `--b-trim`
  = metal 70 % + cream 30 %, 1 px of half-black), a radial key light
  `120% 100% at 18% 0%` (white 7 % → 1.5 % at 38 % → black 22 % at the far
  edge — top-left light, the family rule), and a repeating 92° grain of
  ±1.2 % at 1 px pitch. Bevel and lip: `inset 0 1px 0 bevel-light, inset 0
  −1px 0 bevel-shadow, inset ±1px 0 0 black 35 %, inset 0 12px 18px −14px
  black 80 %` (the shadow the top lip throws onto the deck). Corners 4 px.
  Nothing flat; no hex.
* **End-cheeks.** `--al-material-wood` under a 93° repeating figure of
  three wood tones — `--b-wood-light` (wood 78 % + metal), the wood token,
  `--b-wood-dark` (wood 55 % + recess) at 1 / 2 / 1 / 3 px — and a 180°
  wash from white 14 % at the top to black 32 % at the foot; edges by
  `box-shadow`: a white 22 % top (and left, on the left cheek) edge, a
  black 50–55 % inner and bottom edge. Each cheek rounds only its outer
  corners (4 px); 0.875 rem wide, full bridge height (measured 14 × 293).
* **Screws.** Four 6 px `span`s: radial metal head lit at 35 % / 32 %
  (`--al-material-metal` → `-metal-shadow` → `--al-bevel-shadow`), a 135°
  slot gradient, a 1 px dark ring and a drop shadow.
* **Legend and module titles.** `EngravedLabel` — the approved engraved
  cut (dark copy up, highlight copy down, gradient-clipped glyphs) — `h2`
  size `sm` (11 px measured) for `METER BRIDGE`, `h3` size `xs` (10 px) for
  the module titles, `h4` for `CORRELATION`. Condensed label face confirmed
  in the running app (`"Roboto Condensed", "Arial Narrow", …`).
* **Module outlines.** Each module is a 1 px groove: `box-shadow: inset 0 0
  0 1px var(--al-bevel-shadow), inset 0 1px 0 1px white 4.5 %, 0 1px 0
  white 4 %` (dark groove, its lower lip catching the light) — a panel
  division, not a card: no fill, no elevation.

### Master stereo VU meters (plan §3; 1.5 approved component; most prominent)

* Two `<VUMeter label="Left"/"Right">` with `name="Master left, simulated"`
  etc., no prop overrides of face, arc, needle, hub, overload, recess or
  lamp — the approved artwork at the approved default `lamp` on and
  `lampDrift` on. Size via the component's own `--vu-width` variable,
  stepped by container width: 12 rem (deck content ≥ 1150 px), 13.5 rem
  (≥ 1180), 15 rem (≥ 1240), 16.5 rem (≥ 1290), 18 rem (≥ 1340); 10 rem in
  wrap mode (≥ 700), 7.5 rem under 420 px. At 1280 × 900 the windows measure
  216 × 151.2 px each (channel windows 78 × 54.6 — 2.77× smaller), at
  ≥ 1440 wide 288 px. The `.master__pair` is a flex pair 12 px apart
  (`--al-space-md`; 8 px under 420 px) with `margin-inline: auto`; its module
  scrolls (`overflow-x: auto`) only if a window could ever be narrower than
  the pair.
* L / R distinction: the component's own engraved `LEFT` / `RIGHT` legends
  under each window, and different fixture readings (−3.2 / −1.4 VU) so the
  needles sit visibly apart.

### Spectrum ladder (plan §3; spec §4b "ladder only where called for"; distinct from VU)

* `SpectrumLadder` renders fifteen `<LedLadder level={band.level}
  {segments}>` — the approved component, unchanged — with `segments =
  SPECTRUM_SEGMENTS`, which is `LED_LADDER_SCALE.map(({ db, band }) => ({
  db, band }))`: the approved sixteen thresholds (−40 … +4) and

### Correlation / goniometer (plan §3; provisional D2.1.4)

* `Goniometer` — the task's only SVG, `viewBox 0 0 100 100`, 100 × 100 px
  measured. Floor: radial gradient from `--g-floor-centre` (recess 84 % +
  surface) to `--g-floor-edge` (recess 92 % + black), a faint top-left sheen
  (white 7.5 % → 1.2 % → 0). Graticule (`data-part="graticule"`): the L and
  R diagonals and the ring r = 42 as 0.5-wide, 20 %-opacity strokes, a
  0.9-unit centre pin, `L` / `R` print at 6.5 units in the label face at
  62 % — all in the graticule tone, engraved into the glass. Trace: one `<polyline>` of the
  960 fixture points drawn three times — bloom (`--al-material-lamp`, width
  3.4, opacity 0.26, `feGaussianBlur stdDeviation 1.8`), body (lamp, 1.25,
  0.66), core (`--al-function-amber-hi`, 0.5, 0.92) — the warm phosphor
  behind glass, not a VFD; no green anywhere in the file's CSS (guarded).
  Frame: a 1 px padding ring painted metal → frame → bevel-shadow top to
  bottom (lit top edge), 3.5 px radius; the glass inside carries the lip's
  shadow (`inset 0 2px 3px black 80 %`) and a 1 px `--al-border-strong`
  ring. `role="img"` with an `aria-label` describing the pattern.
* `CORRELATION` strip: `h4` engraved; a 96 × 8 px slot in the recess token
  (`inset 0 1px 2px black 85 %`, 1 px `--al-border-strong` ring); a lit
  index 4 px wide (amber-hi → lamp → amber-base vertical gradient, with a
  3 px lamp-coloured glow) positioned at `(value + 1) / 2` of the slot (measured
  index centre at 0.81 of the slot width for +0.62); `−1 0 +1` as three
  `EngravedLabel size="xs"` (the real minus sign U+2212 as a literal
  character — Svelte attributes do not process `\u` escapes). `role="meter"`
  `aria-valuemin="-1" aria-valuemax="1" aria-valuenow="0.62"`.
* Per-instance SVG ids (`gonio1-floor`, `gonio1-bloom`, …) so a second
  instance could never collide.

   top row's first slot, and the top row is the channel group with spectrum

   is what lets the Phase 0 bank still fit without scrolling at 1280 × 900
   and above. It also leaves the free panel between the groups for Task
