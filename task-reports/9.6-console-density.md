## 1. What changed

| Zone | Before (9.5) | After (this task) |
| --- | --- | --- |
| Density | 1× everywhere; the owner zoomed the browser to 80% | **0.8× in one scope** — every spacing and type token re-declared on `.console-room`; tokens.css untouched; nothing outside the room affected |
| Meter bridge | PHASE · GONIOMETER · SPECTRUM · MASTER, engraved titles, 138 px | **SPECTRUM · GONIOMETER · CORRELATION · MASTER, no legends, 83 px**; every instrument drawn from one height (`--b-inst-height: 4.5rem`) so it fills its box exactly; the spectrum spreads across the deck's free width; VUs print no LEFT/RIGHT, the needle meter runs bare |
| Transport bar | 99 px; floating TIME/STATUS legends; "Automatic mix" under MIX | **53 px ("almost cut in half")**; caps 1.6rem, windows 2.75rem = the keys' column height, MIX 5×1.9rem; the bar runs bare (legends optional in LampDisplay, MIX's line clipped but kept for a11y); glass type 1.0625rem/0.8rem |
| Channel strips | 9rem = 144 px; knobs 40 px; fader 72 px; switches 28 px | **7.2rem = 115.2 px; knobs 32 px; fader 57.6 px; switches 22.4 px** — every control × 0.8, proportions unchanged |
| Tracks / Returns boundary | none (grid gap only) | **a walnut divider** — 0.4375rem, the cheeks' own grain, its own grid column (`"tracks split returns bus"`) — the owner's green line |
| Rails | snap `proximity` + edge fade masks | **snap `mandatory`, fades deleted** — a scroll always releases on a whole module |

New component surface: `CorrelationMeter` `legend` prop, `Goniometer` host-settable
`--gonio-strip-width` (both fallbacks now at the use site, the VU's pattern),
`SpectrumLadder` `spread` prop, `LampDisplay` optional `legend`.

## 2. Measured, not asserted

In a real browser (the production build served and the 20-track fixture session loaded
through the project store):

| Viewport | Room vertical scroll | Transport bottom edge | Bridge / bank / transport |
| --- | --- | --- | --- |
| 1920×1080 | **0 px** | 1074 px (8 px spare) | 83 / 874 / 53 px |
| 1536×864 | **0 px** | 858 px (6 px spare) | 83 / 658 / 53 px |
| 1366×768 | **0 px** | 762 px (6 px spare) | 83 / 562 / 53 px |

Both transport windows' glass fits its print exactly (`scrollHeight === clientHeight`, after
the window height was tuned from the measured 7 px clip). Strip width 115 px; the divider
renders 7 px wide, full rail height. Three VLM review passes of full-page screenshots; the
findings fixed in the rounds: the goniometer's root-level size declarations overriding the
host's values (scope 100 px instead of 72 — moved to use-site fallbacks), the clock glass
clipping its bar·beat line, the floating window legends colliding with the deck's trim, and
— caught by the delivery re-check — the goniometer's correlation strip still printing its
"Correlation" legend on the face (clipped out now, kept for the accessibility tree, pinned
by a new bridge-guard assertion).

## 3. Known behaviour, kept deliberately

At rest, a session with more tracks than the window holds still shows a partial strip at the
fold (mandatory snapping cannot quantize a fluid viewport width; the pure-CSS escape breaks on
the scrollbar's platform-dependent width — see D9.6.6). Every DAW folds channels this way, and
the owner's own sessions (8 tracks + 3 Returns + 1 bus, their screenshot) fit whole with room
to spare at 1536×1080-class widths.
