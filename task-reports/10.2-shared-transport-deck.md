## 3. One defect the measurement caught (fixed in-task)

The first run measured the deck at **52.5 px on Console but 50.4 px on Mixer and
Arrange**, with every control sitting ~1 px lower on the latter two: the MIX column —
the bar's tallest content (D9.6.2: MIX stands over the keys) — was also its height
driver, so `{#if showMix}` shortened the bar's line. Fixed by flooring the body at the
column's own written-down height (`--bar-line`, D10.2.2); the second run measured
52.6 px on all three tabs with identical control positions.

## 6. Review change D10.2.5 — the readout holds one size (2026-11-13)

**Owner:** "the small screen in the transport bar, the one shows the bar/beat
count is dynamic, it become smaller when the beat count is 1, and bigger when
the beat is either 2/3 or 4, it should stay static with one size."

Root cause — in the face, not the layout: the shipped Orbitron Medium subset
is proportional with no tabular-figures feature (the digit `1` advances 391
units against 826–834 for the others; the font folder's README had the quirk
written down since Task 2.3), and the time window is content-sized, so it
breathed with every tick: **measured 6.00 px on every bar** of this build
(bar 1: 101.97 px at beat 1 against 107.97 at beat 4), with the status window
and MIX riding along. `font-variant-numeric: tabular-nums` was already in
LampDisplay's CSS — honest CSS over a face that cannot honour it.

Fix — in the shipped subset, not the layout: `scripts/make-orbitron-tabular.py`
normalises the ten digits to one written-down advance (834 units, the cell `0`
and `8` already occupy) with the ink centred in each cell — the seven wide
digits keep the designer's own metrics, only `1`, `4` and `7` move. Letters,
kerning (letters only) and the original TTF untouched; the script is committed
and idempotent; both font files' SHA-256 are pinned in `check:console-transport`
(section 9a). No component, CSS or layout line changed.

Measured, before → after (Playwright, two synthetic stems, the deck playing):
per-bar beat variance **6.00 px → 0.00 px** — 111.97 px at every beat of every
bar; the same-bar beat-1 vs beat-4 crops differ only inside the beat digit's
own 26 px cell (before: x 270–725 — the window edge and everything after it
moved). The 10.2 contract holds with the tabular face: deck 52.6 px, body
46.2 px (the bar-line floor), one line, fully visible on all three tabs at
1920×1080 and 1366×768; the settled width is absorbed by the status window's
flex. All 33 guards pass; svelte-check 0/0; the suite 477/477; the build
clean. Evidence: `tabular-*` in this folder. Decision **D10.2.5** in
`decisions-log.md`.
